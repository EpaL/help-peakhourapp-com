The Configuration Assistant walks you through adding a new Monitor or editing an existing one, step by step. It opens whenever you add a monitor or edit an existing one's connection settings.

## What is a Monitor?

A Monitor tracks one aspect of your network. PeakHour has two types:

- **[Bandwidth Monitor](/user-guide/settings/monitors-settings/bandwidth-monitor/)** — measures the upload and download throughput of a device, such as your router or your Mac.
- **[Latency Monitor](/user-guide/settings/monitors-settings/latency-monitor/)** — measures the latency to a hop or host on the internet, letting you see the latency between you and that endpoint, or between two endpoints (differential latency).

You can configure as many monitors as you wish (or as your Mac can handle!).

## Choosing the monitor type

The first screen of the assistant asks which kind of monitor to add. Pick the type, then follow the matching walkthrough:

- [Adding a Bandwidth Monitor](/user-guide/configuration-assistant/configuration-assistant-bandwidth/) — choose a device, select an interface, verify, and finish.
- [Adding a Latency Monitor](/user-guide/configuration-assistant/configuration-assistant-latency/) — set the host or hops to measure.

:::tip
If you're unsure how to set up your monitors, choose **File → First Time Setup** to run the guided setup assistant, which configures sensible defaults for you. See [First Time Setup](/user-guide/first-time-setup/).
:::

The **Display** tab contains options for customising how the device is displayed.

## View

<table>
<tbody>
<tr class="odd">
<td><strong>Graph View</strong></td>

</tr>

<img src={img2.src} width="366" alt="CleanShot 2024 05 25 at 11.36.22@2x 20240525 153627" /></td>
</tr>

<td><strong>Retain</strong></td>
<td>Sets how many minutes of data the main graph will retain. The main graph can be scrolled vertically with either the mouse or trackpad, allowing you to see data up to 12 hours in the past. Note that larger values here can impact performance.</td>
</tr>

</table>

## Colors

Here you can customize the colors that are used to indicate latency. The monitor uses colors to indicate relative latency. Colors are blended from Normal (minimum latency) up to Light congestion up to Heavy congestion using a gradient. Also, if configured, the background of the monitor will change to reflect the latency as well.

![CleanShot 2024 05 25 at 13.41.41@2x 20240525 174145](./display-colors-connection-quality-images/cleanshot-2024-05-25-at-13-41-41-2x-20240525-174145.png)

# Colors

<table>
<tbody>
<tr class="odd">
<td><strong>Normal</strong></td>
<td>This is the base color that represents 'good' or 'optimum' connection quality. How the minimum latency is calculated can be configured under <a href="/user-guide/settings/monitors-settings/connection-quality-monitor/latency-options/">Latency options</a> .</td>
</tr>
<tr class="even">
<td><strong>Light Congestion</strong></td>
<td>The color that represents slight congestion.</td>
</tr>
<tr class="odd">
<td><strong>Light Congestion Latency</strong></td>
<td>This value adjusts what is considered 'slight' congestion. By default, <strong>Slight congestion</strong> = <strong>Normal latency</strong> + 75ms.</td>
</tr>
<tr class="even">
<td><strong>Heavy Congestion</strong></td>
<td>The color that represents significant congestion.</td>
</tr>
<tr class="odd">
<td><strong>Heavy Congestion Latency</strong></td>
<td>This value adjusts what is considered 'significant' congestion. By default, <strong>Significant congestion</strong> = <strong>Minimum latency</strong> + <strong>Slight congestion latency</strong> + 125ms.</td>
</tr>
<tr class="even">
<td><strong>Packet Loss</strong></td>
<td><p>The color that represents packet loss. Packet Loss isn’t plotted on the graph as a series, rather it is shown as a grey</p>
<img src={img3.src} width="345" alt="CleanShot 2024 05 25 at 13.36.12@2x 20240525 173616" /></td>
</tr>
</tbody>
</table>

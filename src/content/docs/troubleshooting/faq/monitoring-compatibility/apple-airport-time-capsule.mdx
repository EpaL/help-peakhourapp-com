:::note
Apple discontinued the entire AirPort line in 2018. The compatibility information below is unchanged from earlier versions of PeakHour and remains accurate for these devices.
:::

Below is a summary of AirPort Express / AirPort Extreme / Time Capsule compatibility with PeakHour:

| **Device** | **Compatible** |
|---|---|
| **AirPort Extreme / Time Capsule** | |
| AirPort Extreme / Time Capsule 1st–5th generation (2007–2012) | Yes |
| AirPort Extreme / Time Capsule 6th generation (2013+) | No |
| **AirPort Express** | |
| AirPort Express 1st generation (2004–2008) | No |
| AirPort Express 2nd generation (2008–2012) | Yes |
| AirPort Express 3rd generation (2012+) | Yes |

#### A note about the AirPort Extreme / Time Capsule 2013 and later

Apple removed all support for SNMP from its 2013-and-later AirPort hardware, making those models impossible to monitor (with any software). There is further discussion about the issue on Apple's support forum: [Apple Support Discussion — SNMP and 2013 Airport/Time Capsule](https://discussions.apple.com/thread/5101886).

If you have one of these routers, you can still use PeakHour to monitor this Mac, [other Macs](/user-guide/monitor-another-mac-peakhour-enabler/), PCs, servers and other SNMP-compatible devices on your network. PeakHour's [latency monitors](/user-guide/main-view/latency-monitors/) also let you monitor the responsiveness of your connection regardless of router compatibility. See the [Bandwidth Monitoring FAQ](/troubleshooting/faq/monitoring-compatibility/bandwidth-monitoring-faq/) for more information.

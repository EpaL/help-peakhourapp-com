You can grab the latest build for older versions of PeakHour by following the instructions below:

**PeakHour 5 and 6**

PeakHour 5 and 6 are delivered through the same Mac App Store listing — the current [Mac App Store](https://apps.apple.com/us/app/peakhour/id1560576252?mt=12) build replaces PeakHour 5.

**PeakHour 4**

Click the following link to download the latest build:

- [PeakHour 4.dmg](https://updates.peakhourapp.com/releases/PeakHour%204.dmg)

**PeakHour 3**

Click the following link to download the latest build:

- [PeakHour 3.dmg](https://updates.peakhourapp.com/releases/PeakHour%203.dmg)

**PeakHour 2**

Launch the Mac App Store, click the **Purchases** tab and click **Install** next to **PeakHour**.

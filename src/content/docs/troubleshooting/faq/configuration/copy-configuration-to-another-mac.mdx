---
title: "How do I copy my configuration to a different Mac?"
description: "Move your PeakHour settings and history to another Mac by copying the app's container directory."
sidebar:
  label: Copy configuration to another Mac
status: reviewed
---

1.  Ensure PeakHour is not running on either Mac.

2.  Copy the directory `~/Library/Containers/com.digitician.peakhour5` to `~/Library/Containers` on the target Mac.

3.  Reboot the destination Mac. This ensures any previously cached preferences are cleared.

4.  Start PeakHour on the destination Mac.

:::tip
If you just want your settings (and history) shared between Macs on an ongoing basis, consider enabling [iCloud Sync](/user-guide/settings/icloud/) instead.
:::

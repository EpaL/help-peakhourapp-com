SNMP, or Simple Network Management Protocol ([Wikipedia: SNMP](https://en.wikipedia.org/wiki/Simple_Network_Management_Protocol)), is a protocol that allows devices to be managed remotely over the network. SNMP provides a wide array of capabilities for monitoring and configuration.

PeakHour can use SNMP to provide information about each interface on your network device(s) and the amount of traffic passing through it. PeakHour supports SNMP v1, v2c, and v3.

## Support for SNMP

SNMPv1 has been around since 1988 and is widely supported by many types, makes and models of network devices. This is especially true of enterprise networking hardware, where it is considered the gold standard.

In residential network devices, SNMP is sometimes seen as a 'high end' feature and is therefore only supported by some routers.

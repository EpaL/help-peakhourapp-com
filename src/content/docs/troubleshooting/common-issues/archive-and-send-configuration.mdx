Occasionally, support may ask for a copy of your configuration to assist with troubleshooting.

Follow these steps to capture your configuration so that it can be sent to support for analysis:

1.  Ensure PeakHour is not running.

2.  In **Terminal**, execute the following command:

    ```sh
    zip -ry peakhour-config.zip ~/Library/Containers/com.digitician.peakhour5
    ```

3.  Follow directions from support to provide them with the archived configuration (`peakhour-config.zip`).

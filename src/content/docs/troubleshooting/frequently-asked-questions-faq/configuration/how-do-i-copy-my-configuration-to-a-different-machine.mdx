---
title: "How do I copy my configuration to a different machine?"
description: "1. Ensure PeakHour is stopped on both machines."
sidebar:
  order: 35
status: needs-review
---



1.  Ensure PeakHour is stopped on both machines.

2.  Copy the directory \~/Library/Containers/com.digitician.peakhour5 to \~/Library/Containers on the target machine.

3.  Reboot the destination Mac. This will ensure any previously cached preferences are cleared.

4.  Restart PeakHour.

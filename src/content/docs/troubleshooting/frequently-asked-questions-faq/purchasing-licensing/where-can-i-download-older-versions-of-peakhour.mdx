You can grab the latest build for older versions of PeakHour by following the instructions below:

**PeakHour 2**

Launch the Mac Appstore, click the **Purchases** tab and click **Install** next to **PeakHour**.

**PeakHour 3**

Click the following link to download the latest build:

- [PeakHour 3.dmg](https://updates.peakhourapp.com/releases/PeakHour%203.dmg)

**PeakHour 4**

Click the following link to download the latest build:

- [PeakHour 4.dmg](https://updates.peakhourapp.com/releases/PeakHour%204.dmg)

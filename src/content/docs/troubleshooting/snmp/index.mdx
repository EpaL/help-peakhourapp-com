Troubleshooting problems when monitoring devices over [SNMP](/troubleshooting/reference/snmp/):

- **["No Interfaces Found" when choosing an interface](/troubleshooting/snmp/no-interfaces-found/)** — usually a permissions or community-string problem.
- **[Your device is responding to PeakHour but no data is being reported](/troubleshooting/snmp/device-responds-but-no-data/)** — some routers can't handle many OIDs per query.

New to SNMP? The [SNMP](/troubleshooting/reference/snmp/) and [SNMP Community](/troubleshooting/reference/snmp-community/) reference pages explain the basics.

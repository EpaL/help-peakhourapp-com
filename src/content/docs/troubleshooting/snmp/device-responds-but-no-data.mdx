We have found that a very small number of routers will send a blank SNMP reply if more than a certain number of SNMP OIDs are requested simultaneously.

You can adjust the number of OIDs that PeakHour will send in a single request using the following steps:

1.  Quit PeakHour / make sure it is not running.

2.  Open **Terminal** (click the Spotlight icon in the menu bar, type 'Terminal', then hit Enter).

3.  In Terminal, enter the following command:

    ```sh
    defaults write ~/Library/Containers/com.digitician.peakhour5/Data/Library/Preferences/com.digitician.peakhour5.plist SnmpMaxOidsPerQuery 1
    ```

4.  Start PeakHour.

If this worked, your router should now respond to PeakHour normally.

:::tip
Reducing the number of simultaneous OIDs sent increases the amount of work both PeakHour and your router have to do. For optimal performance, you may want to increase the number to find the 'breaking point' for your router, and keep the value just under that.
:::

When attempting to add a target using SNMP, you get a **No Interfaces Found** error on the **Interface selection** screen.

## What does this error mean?

The most common reason for this error is inadequate permissions with the SNMP device you're talking to.

Some reasons for this include:

  - You enabled SNMP on your Mac using [PeakHour Enabler](/user-guide/monitor-another-mac-peakhour-enabler/) but didn't enable the **From other computers** checkbox.

  - You're using an incorrect [SNMP community](/troubleshooting/reference/snmp-community/).

## How can I fix it?

Some steps you can take to try to fix it:

1.  Make sure you are entering the correct SNMP community / password.

2.  If you used [PeakHour Enabler](/user-guide/monitor-another-mac-peakhour-enabler/) and didn't check the **From other computers** checkbox, make sure you are clicking **Add SNMP Device…** and are specifying `localhost` as the hostname.

    If this doesn't work, run PeakHour Enabler again, enable the **From other computers** checkbox and try again.
